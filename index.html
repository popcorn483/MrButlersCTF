Toolkit

School computers block Inspect Element, so this site has its own tools. At the real event you'll usually have the internet, so learn the names: the decoder here works like CyberChef, and View HTML does the job of View Source (Ctrl+U).

New to these? No problem — here's exactly what each one is for and when to reach for it.

How and when to use each tool
Done decoding? Head back and submit your flag.

My progress

Your work saves automatically in this browser as you go. But school computers often wipe browser storage when you log off — so before you leave, save your progress one of these two ways and bring it back next time.

1

Resume code easiest

Copy your code and keep it somewhere safe — paste it into OneNote, a note to yourself, or an email. Next time, paste it back to carry on exactly where you left off.

Got a code from last time? Paste it here
2

Progress file

Prefer a file? Download one as a backup and load it next time. Teachers collect these for the leaderboard.

🖥 Run a class mock event

A big-screen countdown and live-style scoreboard for a whole-class dress rehearsal. Put it on the projector, start the clock, and have teams work through the Test area on their own devices.

Teacher leaderboard

Ask pupils to download their progress file and send it to you (Teams, shared drive or email). Load them all here at once to build a class leaderboard. Nothing is uploaded anywhere; it all stays on this computer.
